Build the POC

Free instances only. Code lives in the lab/ directory.

0. Instances

  1. Salesforce: developer.salesforce.com/signup. Username must look like an email and be globally unique. API host is *.my.salesforce.com, not lightning.force.com.
  2. ServiceNow: developer.servicenow.com → Request Instance. One PDI. Reclaimed after 10 days without Developer Site activity.

1. Prove the Table API

export SN_INSTANCE=https://devNNNNN.service-now.com
export SN_USER=admin
export SN_PASSWORD='…'
bash lab/scripts/curl_level1.sh

Expect HTTP 201 and an INC number. ServiceNow is the system of record for that new Incident. Nothing calls back.

2. Salesforce → ServiceNow

  1. On the PDI, add incident fields u_sf_case_id and u_sync_source.
  2. Scripted REST API, POST resource, script from lab/servicenow/scripted_rest_bond_case.js. It upserts on u_sf_case_id.
  3. Salesforce: External Credential + Named Credential EBOND_ServiceNow. Deploy lab/salesforce.
  4. Create a Case. The after-insert trigger enqueues a Queueable. The Queueable callout runs after the save, so it does not hit "uncommitted work pending".

3. ServiceNow → Salesforce

  1. Salesforce External Client App (not a Connected App). Client credentials or JWT bearer. My Domain token URL only.
  2. REST Message EBOND Salesforce Case as in lab/servicenow/rest_message_notes.md. PATCH /sobjects/Case/Snow_Sys_Id__c/${snow_sys_id}.
  3. Async business rule lab/servicenow/business_rule_async_sync.js. It returns immediately if u_sync_source is salesforce.

Field ownership

Salesforce owns Subject and Priority. ServiceNow owns state, assignment, work notes. Shared description uses last writer only when Snow_Sync_Source__c / u_sync_source says the other side did not just write it. Correlation key is Snow_Sys_Id__c (external id, unique) paired with u_sf_case_id.

What not to use on the free tier

  • New Connected Apps — creation blocked since Spring '26. Use an External Client App.
  • Salesforce Functions — retired.
  • Integration Hub Salesforce spoke — often not activatable on a PDI. Treat as optional, not the POC path.
  • Guest-user Sites for the webhook — unauthenticated. Use the integration user.
