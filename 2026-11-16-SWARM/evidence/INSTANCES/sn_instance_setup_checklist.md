# Evidence — ServiceNow instance setup checklist

- Portal: https://developer.service-now.com
- Instance URL format: `https://<instance>.service-now.com`
- Admin user: `admin` (password viewed once in portal).
- Free tier: full platform UI, Flow Designer, REST APIs; Integration Hub availability varies — verify in-instance.
- Lifecycle: dev instances may be reset weekly; keep active by logging in; version all config.
