# Evidence — Salesforce Developer org setup checklist

- Signup: https://developer.salesforce.com/signup
- Login: https://login.salesforce.com (username is email-formatted).
- Developer Edition: Flow builder, connected apps, REST/SOAP APIs, named credentials, Dev Hub.
- Lifecycle: DE orgs may deactivate after ~7 days idle; log in periodically.
- Limits: daily API request + storage limits; check in Setup → Company Information.
